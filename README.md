# 🏥 SIAP PULANG — Pusat Informasi & Edukasi Pasien

**SIAP PULANG** adalah aplikasi web interaktif berbasis React dan TypeScript yang dirancang untuk membantu pasien dan keluarga mempersiapkan informasi perawatan medis sebelum dan sesudah pulang dari rumah sakit (*discharge planning*).

Proyek ini dibangun menggunakan pendekatan **Vibe Coding** memanfaatkan AI (*Bolt.ai*) untuk mempercepat alur pengembangan software dari konsep hingga menjadi aplikasi yang siap digerakkan.

---

## ✨ Fitur Utama
* 📖 **Materi Edukasi Diagnosis:** Informasi terstruktur mengenai penyakit, penggunaan obat, diet, dan aktivitas harian (Diabetes, Hipertensi, Gagal Jantung, dll.).
* 📋 **Checklist Pemahaman:** Evaluasi mandiri untuk memastikan pasien memahami instruksi perawatan.
* ✍️ **Kuis & Evaluasi:** Pengujian pemahaman pasien terhadap materi edukasi yang telah dibaca.
* 📅 **Jadwal Kontrol & Dokumen:** Pengingat jadwal konsultasi lanjutan beserta daftar dokumen wajib.
* 🚨 **Panduan Tanda Bahaya:** Informasi mendesak terkait indikasi gawat darurat yang memerlukan tindakan medis segera.

---

## ⚡ Development Approach: Vibe Coding
Aplikasi ini dikembangkan dengan teknik **Vibe Coding** bersama **Bolt.ai**:
* **AI-Assisted Prototyping:** Pemanfaatan prompt AI untuk menghasilkan struktur komponen, logika navigasi, dan antarmuka UI secara cepat.
* **Rapid Iteration:** Proses *refactoring*, penyesuaian tata letak, dan pengayaan materi edukasi dilakukan secara *real-time* berbasis umpan balik interaktif.

---

## 🛠️ Tech Stack
* **Development Method:** Vibe Coding via Bolt.ai
* **Framework/Library:** React, Vite
* **Language:** TypeScript
* **Styling:** CSS / Tailwind CSS
